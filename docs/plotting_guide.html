1. Overview

Mofography has two 3D rendering backends. Default for new work: Three.js (interactive HTML, large scenes). Plotly remains best for notebook go.Figure workflows and 2D PSD curves.

Backend Module Trace type Assemble with
Three.js mofography.threejs_viz + movies Trace dict / bundle Figure3D, Figure3js, or show_mof_threejs
Plotly mofography.visualize Mesh3d, Scatter3d plotly.graph_objects.Figure

Related: docs/tutorial_figure3d.org, docs/native_granular_viz.org.

2. Quick start

Plotly (notebook): 

import plotly.graph_objects as go
import mofography as mgr

fig = go.Figure(
    data=[*mgr.plot_framework_as_mesh(mat_updated), mgr.plot_cell(mat_atoms)],
    layout=mgr.white_layout,
)
fig.show(renderer="firefox")

Three.js (HTML scene): 

from mofography import Figure3js

fig = (
    Figure3js(layout="white", stylize=True)
    .plot_framework_as_mesh_3js(mat_updated, stylize=True)
    .plot_cell_3js(mat_atoms, color="orange")
)
fig.to_html("scene.html")

3. API naming (migrated)

Backend Call pattern Figure object
Plotly (notebooks, go.Figure) mgr.plot_cell, mgr.plot_surface_dgrid, … plotly.graph_objects.Figure
Three.js (interactive HTML, default for new 3D work) mgr.plot_cell_3js, mgr.plot_surface_dgrid_3js, … Figure3js (alias Figure3JS)
  • Plotly names are unchanged — existing tutorials keep working.
  • Three.js uses an explicit _3js suffix so backends never shadow each other.
  • Figure3js.add_trace / .add_traces reject Plotly traces; use mgr.add_traces_plotly(fig, …) for Plotly with the same validation.

4. Figure containers — which object to build

Container Backend Typical use
go.Figure(data[…], layout=mgr.whitelayout)= Plotly Jupyter / Firefox renderer; combine Mesh3d + Scatter3d
Figure3D() (MovieFigure) Three.js Low-level: .add_framework(), .add_cell(), .add_surface(), .to_html()
Figure3js() Three.js Fluent API: .plot_*_3js() (same args as Plotly) on top of Figure3D
show_mof_threejs(seg, atoms, …) Three.js One-shot scene from segmentation dict
show_mof_plotly(seg, atoms, …) Plotly One-shot Plotly scene 
from mofography.movies import Figure3D
from mofography import Figure3js
import mofography as mgr

# Figure3D — canonical Three.js builder (same class as MovieFigure)
fig3d = Figure3D(layout="white")
fig3d.add_framework(mat_updated).add_cell(mat_atoms).to_html("scene.html")

# Figure3js — chaining sugar on top of Figure3D
fig = (
    Figure3js(layout="white")
    .plot_framework_as_mesh_3js(mat_updated, stylize=True)
    .plot_cell_3js(mat_atoms, color="orange")
    .to_html("scene_chain.html")
)

Assume results from do_periodic_segmentation_rust, mat_atoms, mat_updated = update_with_covalent_bonds(mat_atoms), connections_trimmed, cscale (e.g. px.colors.qualitative.Pastel).

Framework mesh mgr.plot_framework_as_mesh(mat_updated, stylize=True) plot_framework_as_mesh_3js(...) or Figure3js().plot_framework_as_mesh_3js(...)

Add traces to Three.js: fig.add_traces(bundle) flattens {"internal": …, "periodic": …} dicts. Do not pass Three.js bundles to go.Figure.

6. Prerequisites

from pathlib import Path
from ase.io import read
import numpy as np
import mofography as mgr

mat_atoms = read(Path("./DUT-75_uncapped.cif").expanduser())
spacing = 0.5
dgrid = mgr.dgrid_from_atoms_rust(mat_atoms, spacing=spacing).astype(np.float32)
results = mgr.do_periodic_segmentation_rust(
    dgrid, mat_atoms, mask_thickness=0.05, h=0.2, spacing=spacing,
    threshold_abs=1.5, min_distance=1.5, return_dgrid=True,
    return_padded_regions=True, extra_padding=2,
)
dgrid = results["dgrid"]
regions = results["regions"]
regions_pbc = results["regions_pbc"]
connections = results["connections"]
all_maxima = results["all_maxima"]
maxima_pbc = results["maxima_pbc"]
unique_regions = results["unique_regions"]
maxima = all_maxima[: regions.max()]
connections_trimmed = [c for c in connections if np.all(np.isin(c[0], unique_regions))]
mat_updated = mgr.update_with_covalent_bonds(mat_atoms)

Connection tuple: [ (n1, n2), has_path, "internal"|"periodic", window_xyz_list, radii_list ].

8. Traces in detail

8.1. Convention:** Plotly → mgr.plot_* on go.Figure. Three.js → mgr.plot_*_3js and Figure3js (chaining methods .plot_*_3js() mirror the functional API).

8.1.1. Framework — mesh (ball-and-stick as mesh)

  1. Plotly
    frame_traces = mgr.plot_framework_as_mesh(
    mat_updated, stylize=True, show_rings=True)
# list of Mesh3d — use [*frame_traces] in go.Figure
    Argument Default Notes
    ase_atoms required Use update_with_covalent_bonds first
    show_rings True Aromatic ring traces
    stylize False Lighting preset
    kwargs_frame_mesh legend/name Passed to Mesh3d
  2. Three.js
    # Functional trace dict
bundle = mgr.draw_framework_3js(mat_updated, representation="mesh", name="Framework")

# Or builder
from mofography.movies import Figure3D
fig = Figure3D().add_framework(mat_updated, show_rings=True)

9. Full examples

9.1. Plotly — DUT-75 notebook figure

import plotly.express as px
import plotly.graph_objects as go
import mofography as mgr

cscale = px.colors.qualitative.Pastel
isovals = [1.0, 1.5]

mat_updated = mgr.update_with_covalent_bonds(mat_atoms)
frame_trace = mgr.plot_framework_as_mesh(mat_updated, stylize=True)
isosurface_pbc = mgr.plot_surface_dgrid(
    dgrid, stylize=True, isovalue=isovals[0], region_labels=regions_pbc,
    ase_atoms=mat_atoms, name="Regions PBC", opacity=1, cscale=cscale,
)
cell_trace = mgr.plot_cell(mat_atoms, color="orange")
maxima_trace_pbc = mgr.plot_maxima(
    dgrid, maxima_pbc, mat_atoms, show_spheres=False,
    marker_size=7.5, marker_colorscale=cscale, name="Maxima (pbc)",
)
connections_traces = mgr.plot_connections_as_it_is(
    connections_trimmed, all_maxima, regions.shape, mat_atoms,
    cscale=cscale, plot_disconnected=False, plot_periodic=True,
)
windows_trace = mgr.plot_windows(
    connections_trimmed, name="Windows",
    marker_color="yellow", marker_size=10, marker_opacity=0.8,
)

fig = go.Figure(
    data=[*frame_trace, cell_trace, maxima_trace_pbc, isosurface_pbc],
    layout=mgr.white_layout,
)
fig.show(renderer="firefox")

9.2. Three.js — same scene as HTML

from mofography import Figure3js

fig = (
    Figure3js(layout="white", stylize=True)
    .plot_framework_as_mesh_3js(mat_updated, stylize=True)
    .plot_cell_3js(mat_atoms, color="orange")
    .plot_surface_dgrid_3js(
        dgrid, isovals[0], mat_atoms, region_labels=regions_pbc,
        cscale=cscale, name="Regions PBC",
    )
    .plot_maxima_from_grid_3js(
        dgrid, maxima_pbc, mat_atoms, cscale=cscale, name="Maxima (pbc)",
    )
    .add_traces(
        mgr.plot_connections_as_it_is_3js(
            connections_trimmed, all_maxima, regions.shape, mat_atoms,
            cscale=cscale, plot_periodic=True,
        )
    )
    .add_traces(
        mgr.plot_windows_3js(
            connections_trimmed, name="Windows", marker_color="yellow",
        )
    )
)
fig.to_html("dut75_scene.html")

10. Global PSD (2D histogram)

import plotly.graph_objects as go
import numpy as np
import mofography as mgr

probe_radius = 0
sample_points, pore_sizes = mgr.compute_pore_sizes_uniform_rust(
    dgrid, mat_atoms, num_samples_total=50000,
)
pore_sizes = pore_sizes[pore_sizes > probe_radius]
bins = np.linspace(0, 100, 1000)
hist, bin_edges = np.histogram(pore_sizes * 2, bins=bins, density=True)
binC = (bin_edges[1:] + bin_edges[:-1]) / 2

mgr_psd_trace = go.Scatter(
    x=binC, y=hist, mode="lines+markers", marker_size=10,
    name="PSD mgr", line=dict(width=2, color="black"),
)
fig = go.Figure(data=[mgr_psd_trace], layout=mgr.white_layout)
fig.update_layout(
    xaxis_range=[0, 27],
    xaxis_title="Pore Diameter (Å)",
    yaxis_title="Normalized Pore Size Distribution",
)
fig.show(renderer="firefox")

Define publication_layout in your notebook if you use a custom layout instead of mgr.white_layout.

12. Troubleshooting

12.1. ValueError: invalid literal for int() with base 10: 'rrr...'

Passed a string or Plotly hex list where Three.js expected RGB tuples. Fixed in movies._normalize_cscale(); use px.colors.qualitative.Pastel or omit cscale.

12.2. plot_windows(...) needs grid_shape and maxima=**

Outdated call pattern. Use plot_windows(connections_trimmed, ...) only, or plot_windows_from_results(...) for reclassification.

12.3. go.Figure crashes with trace dict / bundle

You passed Three.js trace dicts to Plotly. Use mgr.plot_* for Plotly and Figure3js + plot_*_3js for HTML.

12.4. Figure3js.add_trace rejects my trace

You passed a Plotly Mesh3d / Scatter3d. Use the matching plot_*_3js helper or add_traces_plotly for Plotly figures.
