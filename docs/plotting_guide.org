* Overview

Mofography has two 3D rendering backends. **Default for new work: Three.js** (interactive HTML, large scenes). **Plotly** remains best for notebook =go.Figure= workflows and 2D PSD curves.

| Backend | Module | Trace type | Assemble with |
|---------+--------+------------+---------------|
| Three.js | =mofography.threejs_viz= + =movies= | Trace dict / bundle | =Figure3D=, =Figure3js=, or =show_mof_threejs= |
| Plotly | =mofography.visualize= | =Mesh3d=, =Scatter3d= | =plotly.graph_objects.Figure= |

Related: =docs/tutorial_figure3d.org=, =docs/native_granular_viz.org=.


* Quick start

**Plotly (notebook):**

#+begin_src python
import plotly.graph_objects as go
import mofography as mgr

fig = go.Figure(
    data=[*mgr.plot_framework_as_mesh(mat_updated), mgr.plot_cell(mat_atoms)],
    layout=mgr.white_layout,
)
fig.show(renderer="firefox")
#+end_src

* API naming (migrated)

| Backend | Call pattern | Figure object |
|---------+--------------+---------------|
| **Plotly** (notebooks, =go.Figure=) | =mgr.plot_cell=, =mgr.plot_surface_dgrid=, … | =plotly.graph_objects.Figure= |
| **Three.js** (interactive HTML, default for new 3D work) | =mgr.plot_cell_3js=, =mgr.plot_surface_dgrid_3js=, … | =Figure3js= (alias =Figure3JS=) |

- Plotly names are **unchanged** — existing tutorials keep working.
- Three.js uses an explicit =_3js= suffix so backends never shadow each other.
- =Figure3js.add_trace= / =.add_traces= **reject** Plotly traces; use =mgr.add_traces_plotly(fig, …)= for Plotly with the same validation.

* Figure containers — which object to build

| Container | Backend | Typical use |
|-----------+---------+-------------|
| =go.Figure(data=[...], layout=mgr.white_layout)= | Plotly | Jupyter / Firefox renderer; combine =Mesh3d= + =Scatter3d= |
| =Figure3D()= (=MovieFigure=) | Three.js | Low-level: =.add_framework()=, =.add_cell()=, =.add_surface()=, =.to_html()= |
| =Figure3js()= | Three.js | Fluent API: =.plot_*_3js()= (same args as Plotly) on top of =Figure3D= |
| =show_mof_threejs(seg, atoms, …)= | Three.js | One-shot scene from segmentation dict |
| =show_mof_plotly(seg, atoms, …)= | Plotly | One-shot Plotly scene |

* Master trace map (Plotly vs Three.js)

Assume =results= from =do_periodic_segmentation_rust=, =mat_atoms=, =mat_updated = update_with_covalent_bonds(mat_atoms)=, =connections_trimmed=, =cscale= (e.g. =px.colors.qualitative.Pastel=).

| Trace | Plotly (=go.Figure=) | Three.js (=Figure3D= / bundles) |
|-------+----------------------+----------------------------------|
| Framework mesh | =mgr.plot_framework_as_mesh(mat_updated, stylize=True)= | =plot_framework_as_mesh_3js(...)= or =Figure3js().plot_framework_as_mesh_3js(...)= |
| Framework scatter/stick | =mgr.draw_framework(mat_updated, …)= | =draw_framework_3js(...)= or =.draw_framework_3js(...)= |
| Unit cell | =mgr.plot_cell(atoms, color=…)= | =plot_cell_3js(atoms, …)= or =.plot_cell_3js(atoms)= |
| Iso-surface (regions) | =mgr.plot_surface_dgrid(...)= | =plot_surface_dgrid_3js(...)= or =.plot_surface_dgrid_3js(...)= |
| Iso-surface (PBC regions) | same with =region_labels=regions_pbc= | same |
| Maxima (local subset) | =mgr.plot_maxima(dgrid, maxima, atoms, …)= | =plot_maxima_from_grid_3js(..., hide_periodic=True)= |
| Maxima (PBC) | =mgr.plot_maxima(dgrid, maxima_pbc, atoms, …)= | =plot_maxima_from_grid_3js(...)= |
| Connections (internal + periodic) | =mgr.plot_connections_as_it_is(...)= | =plot_connections_as_it_is_3js(...)= |
| Connections (internal only) | =plot_periodic=False= | =plot_connections_3js(seg, atoms, hide_periodic=True)= |
| Windows (simple) | =mgr.plot_windows(connections_trimmed, …)= | =plot_windows_3js(connections_trimmed, …)= |
| Windows (+ far-outside → periodic) | =mgr.plot_windows_from_results(...)= | =plot_windows_from_results_3js(...)= |
| Percolated cluster meshes | =mgr.plot_percolated_cluster_meshes(...)= | =plot_percolated_cluster_meshes_3js(...)= |
| PLD-critical windows | =mgr.plot_percolation_windows(...)= | =plot_percolation_windows_3js(...)= |
| CSD curves (centroid distance, for clustering) | =mgr.plot_csds(rag, pbc_groups, cluster_key=…)= | Plotly only |
| Pocketwise probe PSDs (Rust sampler) | =compute_psds_pocketwise_rust= + =plot_pocket_psds= | Plotly only |
| Full scene | =show_mof_plotly(results, atoms, …)= | =show_mof_threejs(results, atoms, …)= |

**Add traces to Three.js:** =fig.add_traces(bundle)= flattens ={"internal": …, "periodic": …}= dicts. **Do not** pass Three.js bundles to =go.Figure=.

* Prerequisites

#+begin_src python
from pathlib import Path
from ase.io import read
import numpy as np
import mofography as mgr

mat_atoms = read(Path("./DUT-75_uncapped.cif").expanduser())
spacing = 0.5
dgrid = mgr.dgrid_from_atoms_rust(mat_atoms, spacing=spacing).astype(np.float32)
results = mgr.do_periodic_segmentation_rust(
    dgrid, mat_atoms, mask_thickness=0.05, h=0.2, spacing=spacing,
    threshold_abs=1.5, min_distance=1.5, return_dgrid=True,
    return_padded_regions=True, extra_padding=2,
)
dgrid = results["dgrid"]
regions = results["regions"]
regions_pbc = results["regions_pbc"]
connections = results["connections"]
all_maxima = results["all_maxima"]
maxima_pbc = results["maxima_pbc"]
unique_regions = results["unique_regions"]
maxima = all_maxima[: regions.max()]
connections_trimmed = [c for c in connections if np.all(np.isin(c[0], unique_regions))]
mat_updated = mgr.update_with_covalent_bonds(mat_atoms)
#+end_src

** Pocketwise PSDs on =results= and RAG (typing + plots)

| Step | Function | Stores |
|------+----------+--------|
| 1 | =enrich_segmentation_with_pocket_psds(results, atoms, probe_radius_psd=1.2)= | =results["pocket_psds"]= |
| 2a | =assign_pocket_types(results, atoms)= | reuses =pocket_psds= (no second Rust run) |
| 2b | =add_pocket_psds_to_rag_from_segmentation(rag, results, atoms)= | =pocket_psd_x_pbc= / =pocket_psd_y_pbc= on RAG nodes |

Low-level (if you already have histograms): =add_pocket_psd_to_rag_with_pbc(rag, props, pbc_groups, pocket_psds)=.

**Note:** =add_clustering_to_rag_geometry_js= clusters on *centroid-distance* void histograms (same family as =plot_csds=), not on =pocket_psd_*_pbc=. Pocket typing (=env_cluster=) uses probe PSDs + annulus fingerprints.

*** CSD curves — =plot_csds= (NOT pocketwise Rust PSDs)

Plotly only. Plots **cavity size distributions (CSD)** on the RAG: histograms of *distance from the PBC-aware pocket centroid to void voxels* (=csd_x_pbc= / =csd_y_pbc=), from =add_csd_to_rag_with_pbc= (or deprecated =add_psd_to_rag_with_pbc=).

| What | Function / data |
|------+-----------------|
| Build histograms on RAG | =add_csd_to_rag_with_pbc(rag, props, pbc_groups, bins, atoms, shape)= |
| Cluster pockets by CSD shape | =add_clustering_to_rag_geometry_js(...)= → =cluster_geom_pbc= |
| Plot one curve per PBC group | =plot_csds(rag, pbc_groups, cluster_key="cluster_geom_pbc")= |

**=cluster_geom_pbc= only sets line colors** (geometry JS clusters of CSD histograms). It does **not** use the Rust pocketwise probe sampler.

#+begin_src python
from skimage.measure import regionprops
import plotly.graph_objects as go

props = regionprops(regions)
bins = np.linspace(0, 50, 30)
rag = mgr.rag_from_connections(connections_trimmed, maxima)
rag = mgr.add_maxima_to_rag(rag, maxima, maxima_radii, dgrid.shape, mat_atoms)
rag = mgr.add_pbc_to_rag(rag, pbc_groups)
rag = mgr.add_csd_to_rag_with_pbc(
    rag, props, pbc_groups, bins, mat_atoms, dgrid.shape,
)
rag = mgr.add_clustering_to_rag_geometry_js(
    rag, props, pbc_groups, mat_atoms, dgrid.shape,
)

csd_traces = mgr.plot_csds(
    rag, pbc_groups, cscale=cscale, cluster_key="cluster_geom_pbc",
)
fig_csd = go.Figure(data=csd_traces, layout=mgr.white_layout)
fig_csd.update_layout(
    xaxis_title="Distance to centroid (Å)",
    yaxis_title="Normalized histogram",
)
#+end_src

*** Pocketwise probe PSDs (Rust) — =compute_psds_pocketwise_rust=

**Probe-occupiable** pore size distributions: sample points inside each PBC pocket and histogram local clearance from =dgrid=. Matches =make_images.org= (DUT-75 / UMCM-1 textural figures) — **not** =plot_csds=.

| Step | Function |
|------+----------|
| Sample per region | =compute_pore_sizes_pocketwise_rust(dgrid, regions_pbc, atoms, samples_per_region=…)= |
| Bin + optional figure | =compute_psds_pocketwise_rust(..., return_fig=True)= or =plot_pocket_psds_from_grid(...)= |
| Accessible pockets only | =compute_psds_pocketwise_accessible(results, atoms, probe_radius, …)= |
| Store on RAG (fingerprints) | =add_pocket_psd_to_rag_with_pbc(rag, props, pbc_groups, pocket_psds)= |

* Troubleshooting


** =PocketTypingResult(ok=False, error='no pockets extracted from segmentation')=
Pocket typing needs probe-wise PSD histograms on the RAG (=pocket_psd_y_pbc=). That requires =compute_psds_pocketwise_rust(..., probe_center_min_radius=probe_radius_psd)= — if your install lacked that keyword, the call failed silently and =typed.ok= is false. **Fix:** =pip install -e . --no-deps= on current mofography; pass =probe_radius_psd=1.2= (interactive-app default). Cu-BTC should yield **3** types. Always check =if not typed.ok: raise RuntimeError(typed.error)= before plotting =regions_cluster=.

** Confused =plot_csds= with pocketwise PSDs?**
=plot_csds= plots =csd_x_pbc= / =csd_y_pbc= (centroid-distance CSD for geometry clustering). For Rust probe sampling use =plot_pocket_psds_from_grid= or =compute_psds_pocketwise_rust=.

** =ValueError: invalid literal for int() with base 10: 'rrr...'=
Bad =cscale= on Three.js traces. Use =px.colors.qualitative.Pastel= or omit =cscale=.

** =plot_windows(...) needs grid_shape= and maxima=**
Use =plot_windows(connections_trimmed, ...)= only.

** =go.Figure= crashes with trace dict / bundle**
You passed Three.js bundles to Plotly. Use =Figure3js= + =plot_*_3js=.
