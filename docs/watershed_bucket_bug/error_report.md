I found another potential problem with do_periodic_segmentation_rust, which may influence PLD calculations. The watershed segmentation seeded_watershed_bucket in do_periodic_segmentation_rust may result in some points in the void space being labeled as "0". Sometimes, the realistic window is labeled as "0", resulting in a deviation of the PLD. In my testing, the pore segmentation is a little tricky because of the parameters I set. But theoretically it will not influence the PLD. However, as shown in the second figure, the small white balls represent the points with a "0" label. We can see they include the window location. So the calculated PLD is smaller than the correct one. The pseudo material is the simplest one, so I guess this question may occur in MOFs as well.
