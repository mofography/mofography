#+TITLE: Blocking pockets in mofography — NU-1000 example
#+DESCRIPTION: Build blocking spheres (greedy or largest-including), write RASPA BlockPockets files, visualize with Plotly, optional overlap diagnostics.

* Overview

This note shows how to:

1. Segment void space and obtain =regions= / =dgrid= (or load cached results).
2. Build **blocking spheres** for **inaccessible** pockets at a probe radius (e.g. 3.25 Å) using either:
   - *largest-including* (many spheres, PBC-consistent including geometry), or
   - *greedy* (fewer spheres, Euclidean cover of the masked voxels).
3. Write a **RASPA** blocking list (=N= then fractional =x y z r= per line).
4. **Visualize** with =plot_blocking_spheres= — =render_mode= =mesh= / =points= / =centers= / =auto= (see =mofography/visualize.py=).
5. Optionally run **paired** overlap QA (=blocking_spheres_overlap_leakage_pair=): leakage into accessible void *and* coverage of inaccessible void (=mofography/raspa_helper.py=).

All API lives in =mofography= after =import mofography as mgr=.

* Working directory

Snippets below assume the **mofography repository root** as current working directory so that =examples/TestCIFs/NU-1000_S1.cif= and a local =nu-1000_results.pkl= resolve. Adjust paths if you run from elsewhere.

* Prerequisites

- CIF: =examples/TestCIFs/NU-1000_S1.cif= (or your path).
- Python: =mofography=, =ase=, =plotly=, =numpy=.
- Segmentation is expensive; for repeat runs, **pickle** the =results= dict from =do_periodic_segmentation_rust=.

* 1. Load structure and segmentation

**Option A — load cached segmentation** (recommended if you already have a =.pkl=):

#+begin_src python
from pathlib import Path
import pickle
from ase.io import read
import mofography as mgr

cif = Path("examples/TestCIFs/NU-1000_S1.cif")
atoms = read(cif)
atoms_vis = mgr.update_with_covalent_bonds(atoms)

with Path("nu-1000_results.pkl").open("rb") as fh:
    results = pickle.load(fh)

# Spacing must match the segmentation grid. Prefer stored input (Rust segmentation):
spacing = mgr.segmentation_spacing_from_results(
    atoms, results["regions"].shape, results
)
#+end_src

**Option B — compute segmentation** (adjust =spacing= to match your workflow; 0.25 Å is typical for detailed blocking):

#+begin_src python
from pathlib import Path
import numpy as np
from ase.io import read
import mofography as mgr

cif = Path("examples/TestCIFs/NU-1000_S1.cif")
atoms = read(cif)
spacing = 0.25

dgrid = mgr.dgrid_from_atoms_cpu(atoms, spacing=spacing, block_size=50000).astype(np.float32)
results = mgr.do_periodic_segmentation_rust(
    dgrid,
    atoms,
    mask_thickness=0.5,
    h=0.2,
    spacing=spacing,
    return_dgrid=True,
    threshold_abs=1.5,
    min_distance=1.5,
    return_padded_regions=True,
    extra_padding=2,
    compute_connections=True,  # needed for RAG-based overlap / interface helpers
)
#+end_src

* 2. Build blocking spheres (inaccessible pockets)

Use the **same** =probe_radius= (Å) as in your GCMC accessibility definition (e.g. half kinetic diameter).

**Largest-including** (via convenience wrapper):

#+begin_src python
probe_radius = 3.25
spheres_li, percolated, inaccessible = mgr.blocking_spheres_for_probe_radius(
    results,
    atoms,
    probe_radius,
    radius_scale=1.0,
    method="largest_including",
)
#+end_src

**Greedy** (org-note style; Euclidean mask cover, usually far fewer spheres):

#+begin_src python
spheres_g, meta = mgr.blocking_spheres_greedy(
    results,
    atoms,
    probe_radius,
    spacing=spacing,  # must match segmentation grid
    block_accessible=False,  # standard BlockPockets: block inaccessible void
)
#+end_src

For **InvertBlockPockets** workflows, use =blocking_spheres_greedy(..., block_accessible=True)=.

* 3. Write RASPA blocking file

#+begin_src python
out_block = Path("nu1000_blockpockets_greedy.block")
mgr.write_blocking_spheres_file(out_block, spheres_g)
#+end_src

First line = number of spheres; each following line: =sx sy sz r= (fractional center, radius in Å).

* 4. Visualize (mesh spheres, dark layout)

=plot_blocking_spheres= is the single entry point for blocking-sphere Plotly output.

- =render_mode="points"= (default): Fibonacci-sampled shell markers (one trace).
- =render_mode="centers"= or =plot_centers_only=True=: one marker per sphere.
- =render_mode="mesh"=: all spheres merged into **one** =Mesh3d= (=trimesh.util.concatenate= via =plot_mesh=).
- =render_mode="auto"=: pick mesh / points / centers from sphere count (=auto_mesh_max_spheres=, =auto_points_max_spheres=).

You may pass a **plain list** of spheres, or the full return value of =blocking_spheres_greedy= (=spheres, meta)= or =blocking_spheres_for_probe_radius= (=(spheres, percolated, inaccessible)=); the function unwraps tuples automatically.

For hundreds of spheres, =mesh= is heavy; lower =mesh_theta_resolution= / =mesh_phi_resolution= or use =render_mode="auto"=.

=plot_blocking_spheres_styled= is a **deprecated alias** for =plot_blocking_spheres= (same object); prefer =plot_blocking_spheres=.

#+begin_src python
import plotly.graph_objects as go
import mofography as mgr

cell_tr = mgr.plot_cell(atoms)
frame_tr = mgr.plot_framework_as_mesh(atoms_vis, stylize=True)

# Either: spheres_g from section 2, or pass (spheres_g, meta) directly.
block_tr = mgr.plot_blocking_spheres(
    (spheres_g, meta),
    atoms,
    render_mode="mesh",
    mesh_opacity=0.28,
    mesh_color="crimson",
    mesh_theta_resolution=18,
    mesh_phi_resolution=18,
    name="Greedy blocking (inaccessible)",
)

fig = go.Figure(data=[cell_tr, block_tr, *frame_tr], layout=mgr.dark_layout)
fig.update_layout(
    title="NU-1000 — greedy blocking spheres (mesh)",
    scene_aspectmode="data",
)
fig.write_html("nu1000_greedy_blocking_mesh_dark.html", include_plotlyjs="cdn")
#+end_src

* 5. Optional — overlap / leakage + inaccessible coverage (paired QA)

For **BlockPockets** (spheres built to cover **inaccessible** void), you usually want **two** numbers on the same grid resolution:

1. *Leakage* — among **accessible** sample points, what fraction lie **inside** the sphere union? (spill into transport void.)
2. *Coverage gap* — among **inaccessible** sample points, what fraction lie **outside** the union? (missed cages.)

Use =blocking_spheres_overlap_leakage_pair= and =print_blocking_spheres_overlap_pair_report=.

- The **accessible** leg uses =resolution= (=fine=, =coarse=, or =interface=).
- The **inaccessible** leg must be =fine= or =coarse=. If =resolution="interface"=, inaccessible defaults to =fine= unless you pass =inaccessible_resolution="coarse"=.

#+begin_src python
import mofography as mgr

pair = mgr.blocking_spheres_overlap_leakage_pair(
    results,
    atoms,
    spheres_g,
    probe_radius,
    resolution="fine",
    fine_spacing=spacing,
    accessible_dgrid_ge_probe=False,
    per_label=False,
)
mgr.print_blocking_spheres_overlap_pair_report(pair)
#+end_src

Lower-level: =blocking_spheres_overlap_leakage(..., denominator_domain="accessible"|"inaccessible")= and =print_blocking_spheres_overlap_report= for one leg at a time.

- =resolution="fine"=: every voxel center in that void class on the segmentation grid.
- =resolution="coarse"=: subsample at =sample_spacing=; optional =per_label=True=.
- =resolution="interface"=: (**accessible only**) coarse samples on the pocket–channel **interface band** — *not* the same as “all accessible void”; see tutorial text above.

Legacy thin wrappers (=blocking_spheres_overlap_accessible_coarse_sample=, etc.) still exist; prefer the unified names above.
