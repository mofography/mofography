* Overview

This note documents the optimization of the default Rust distance-grid backend exposed as =dgrid_from_atoms_rust= in =mofography/rust_fun.py=. The implementation lives in =mgr_rust/src/dgrid_exp.rs= and is registered in Python as =mgr_rust.dgrid_from_atoms=.

The goal is to compute, for every voxel \(\mathbf{r}\) on a uniform fractional grid, the *surface distance*

\begin{equation}
d(\mathbf{r}) = \min_i \left( \|\mathbf{r} - \mathbf{r}_i\|_{\mathrm{MIC}} - R_i \right)
\end{equation}

where \(\mathbf{r}_i\) are atom centers in fractional coordinates (shifted by \(-0.5\) to match the grid convention), \(R_i\) are van der Waals radii, and \(\|\cdot\|_{\mathrm{MIC}}\) is the minimum-image Cartesian distance under periodic boundary conditions (PBC).

* Motivation

**Original bug.** The first Rust port used per-component fractional wrapping (NINT):

\begin{equation}
\Delta \mathbf{f} = \mathbf{f}_\mathrm{grid} - \mathbf{f}_\mathrm{atom}, \qquad
\Delta \mathbf{f}'_k = \Delta f_k - \mathrm{NINT}(\Delta f_k)
\end{equation}

followed by \(\mathbf{r}' = \mathbf{H}\,\Delta \mathbf{f}'\) where \(\mathbf{H}\) is the cell matrix (columns = lattice vectors). This is the standard algorithm in LAMMPS, GROMACS, and OpenMM for *short* displacements, but it minimizes \(\|\Delta \mathbf{f}\|_\infty\) in fractional space, not \(\|\mathbf{H}\Delta \mathbf{f}\|_2\) in Cartesian space. For *non-orthogonal* cells the fractional cube \([-0.5,0.5)^3\) is not the true MIC Voronoi cell.

**Empirical failure (FOTNIN).** A rhombohedral MOF with 60° angles showed LCD inflated from \(\sim 33.6\) Å (correct) to \(\sim 37\) Å because a pore voxel picked the wrong periodic image: Cartesian distance 28.4 Å instead of 15.9 Å.

**Brute-force fix (intermediate).** Unconditional checks of all 27 fractional images per atom–voxel pair restored correctness but were \(\sim 27\times\) slower.

**Current solution.** A tiered MIC strategy (Wassenaar 2006) plus SoA layout and SIMD on orthogonal cells gives bit-exact agreement with the 27-image brute force on benchmark MOFs at \(\sim 4\)–\(7\times\) lower wall time.

* Coordinate conventions

| Quantity | Convention |
|----------+-------------|
| Grid fractional coords | \(\mathbf{f}_\mathrm{grid} \in [-0.5, 0.5]\), inclusive endpoints (=linspace= style) |
| Atom fractional coords | ASE scaled positions minus 0.5 |
| Cell matrix \(\mathbf{H}\) | =cellpar_to_cell(cellpar).T=; Cartesian \(\mathbf{r}_\mathrm{cart} = \mathbf{H}\,\mathbf{f}\) |
| Output | =float32= array; LCD \(\approx 2 \times \max d\) on the grid |

Default radii: Mendeleev VDW table via =mofography.vdw_radii.default_vdw_radii_angstrom= (same as =dgrid_from_atoms_cpu=).

* MIC theory

**Metric tensor.** For cell matrix \(\mathbf{H}\), the MIC Voronoi cell in fractional space is defined by the metric \(\mathbf{G} = \mathbf{H}^\top \mathbf{H}\). Per-component NINT is exact iff \(\mathbf{H}\) is diagonal (cubic, tetragonal, orthorhombic Bravais types).

**Wassenaar guard (Algorithm 1).** After NINT wrapping, if the returned Cartesian length satisfies

\begin{equation}
\|\mathbf{H}\,\Delta \mathbf{f}'\|_2 < d_\mathrm{max}
= \tfrac{1}{2}\min\bigl(\|\mathbf{a}\|, \|\mathbf{b}\|, \|\mathbf{c}\|\bigr)
\end{equation}

then the result is *provably* the true MIC distance (Wassenaar 2006, Appendix C).

**Face fallback (Algorithm 2).** If \(\|\mathbf{H}\,\Delta \mathbf{f}'\|_2 \ge d_\mathrm{max}\), check the six face-adjacent images \(\Delta \mathbf{f}' \pm \mathbf{e}_k\) (\(k=1,2,3\)) in fractional space. With a *reduced* basis, at most seven images suffice; we use the six offsets \(\pm(1,0,0)\), \(\pm(0,1,0)\), \(\pm(0,0,1)\) applied to the already NINT-wrapped displacement. On all benchmark MOFs this matches unconditional 27-image search.

**When NINT fails.** Typical MOF cells (triclinic, monoclinic, hexagonal) can fail near pore centers whose MIC distance is just above \(d_\mathrm{max}\) — void voxels far from atoms almost always trigger the face fallback.

* Three-tier algorithm

The implementation branches once per structure (not per voxel):

*** Tier 0 — Orthogonal fast path

Detect diagonal \(\mathbf{H}\) (off-diagonals \(< 10^{-12}\)). Then NINT is always exact: one image per atom.

*** Tier 1 — Skewed: NINT + \(d_\mathrm{max}\) certificate

For each atom at a voxel:
1. \(\Delta \mathbf{f}' = \mathrm{NINT\text{-}wrap}(\mathbf{f}_\mathrm{grid} - \mathbf{f}_\mathrm{atom})\)
2. \(s^2 = \|\mathbf{H}\,\Delta \mathbf{f}'\|_2^2\)
3. If \(s^2 < d_\mathrm{max}^2\): accept (Tier 1 exact)
4. Else: fall through to Tier 2

*** Tier 2 — Six face images

Evaluate \(s^2\) for \(\Delta \mathbf{f}'\) and \(\Delta \mathbf{f}' \pm \mathbf{e}_k\), take minimum surface distance.

**Squared-distance pruning** avoids =sqrt= when clearly not the minimum:

\begin{equation}
\sqrt{s^2} - R_i < d_\mathrm{min}
\quad\Longleftrightarrow\quad
s^2 < (d_\mathrm{min} + R_i)^2
\end{equation}

* Performance optimizations

*** Structure-of-arrays (SoA)

Atoms stored as separate =x[], y[], z[], r[]= vectors instead of row-wise =outer_iter()=. Improves cache locality in the hot inner loop.

*** SIMD (`wide::f64x4`) — orthogonal cells only

Process four atoms per iteration: vectorized NINT, matrix–vector product, and squared norm. Scalar tail for =n_atoms % 4=.

*** Rayon parallelization

Outer loop over voxels uses =into_par_iter()= (same as original). Thread count: =RAYON_NUM_THREADS=.

*** Complexity

| Backend | Per voxel (typical) | Notes |
|---------+---------------------+-------|
| Old NINT only | \(O(N_\mathrm{atoms})\) | Wrong MIC on skewed cells |
| 27-image brute | \(O(27\,N_\mathrm{atoms})\) | Exact, slow |
| **Current default** | \(O(N_\mathrm{atoms})\) ortho; \(O(7\,N_\mathrm{atoms})\) worst skewed | Exact on benchmarks |
| =dgrid_from_atoms_aabb_rust= | \(O(k \log N_\mathrm{atoms})\), \(k{=}10\) | Fast; neighbor-count heuristic |

* Validation (spacing = 0.5 Å, Mendeleev radii)

Compared to the retired 27-image brute implementation:

| Material | max \(\|d_\mathrm{rust} - d_\mathrm{brute}\|\) | LCD |
|----------+-----------------------------------------------+-----|
| P1-Cu-BTC | 0.00 | 12.08 Å |
| P1-IRMOF-1 | 0.00 | 15.08 Å |
| FOTNIN | 0.00 | 33.33 Å (was \(\sim 37\) with buggy NINT) |
| WUPNIF | 0.00 | 3.63 Å |
| TOVKOG | 0.00 | 22.81 Å |
| NU-1000 | 0.00 | 29.61 Å |

Compared to =dgrid_from_atoms_aabb_rust= (R-tree reference): LCD agrees within 0.25 Å on all six; local voxel max diff up to \(\sim 0.5\) Å on Cu-BTC/FOTNIN from MIC vs neighbor-query differences.

Representative speedup vs 27-image brute at spacing 0.5 Å: \(\sim 4\)–\(7\times\) (e.g. FOTNIN 1.17 s → 0.17 s, Cu-BTC 0.05 s vs 0.35 s).

* Python API

#+begin_src python
import mofography as mgr
from ase.io import read

atoms = read("examples/TestCIFs/P1-Cu-BTC.cif")
spacing = 0.5

# Default: optimized exact MIC (mgr_rust.dgrid_from_atoms)
dgrid = mgr.dgrid_from_atoms_rust(atoms, spacing=spacing)

# Fast alternative for large cells (R-tree, n_neighbors=10)
dgrid_aabb = mgr.dgrid_from_atoms_aabb_rust(atoms, spacing=spacing)

# Deprecated alias (identical to dgrid_from_atoms_rust)
dgrid_exp = mgr.dgrid_from_atoms_exp_rust(atoms, spacing=spacing)
#+end_src

* When to use which backend

- =dgrid_from_atoms_rust= — **default**; exact MIC brute-force security, good for screening and parity with CPU reference
- =dgrid_from_atoms_aabb_rust= — largest speedups on big grids / many atoms; practically exact for MOFs
- =dgrid_from_atoms_aabb_interp_rust= — coarse→fine interpolation; fastest HTS, small interpolation error at sharp pore boundaries
