* Overview

Textural surface area and void volume in mofography are built from **three independent choices**:

1. *Accessibility* — which fragment =regions= IDs count as probe-percolating (winding graph **or** lattice voxel history).
2. *Winding add-on* — optional window-fingerprint bridging (**winding only**; needs pore graph).
3. *Geometry estimator* — how area/volume is integrated after accessibility is fixed (mesh SA, MC SA, or voxel void volume).

Winding and lattice are **never mixed** in one call. Both may be computed on the same material and stored side-by-side on the same =results= dict.

** Recommendations

- *Polymers and flexible / graph-sensitive frameworks*: use **winding** accessibility (pore graph captures connectivity Zeo++-style voxels can miss).
- *Surface area accuracy*: prefer **MC** over **mesh** when possible — marching-cubes mesh SA can **drop triangles** at region boundaries and on thin/noisy isosurfaces; MC shell sampling is usually more robust (stochastic noise vs systematic mesh loss).
- *Zeo++ comparison / legacy pipelines*: call explicit **lattice** functions (=variant="v2"= recommended).

* Accessibility methods

** Winding (default for MOFs and polymers)

- Uses directed pore graph + winding-number loops (=mofography/winding_percolation.py=).
- Percolating fragment labels at probe *r*: =percolating_region_labels_at_probe_winding=.
- Stores history on results: =percolation_history_winding=.
- Pore diameters: =get_pore_dia_mgr_winding2= → =pore_dia_winding=.

** Lattice (explicit Zeo++-style)

- Binary void mask on =dgrid=; percolation via voxel labeling (=percolation_all_axes_periodic= in v2).
- No window fingerprint (no graph).
- Stores history: =percolation_history_lattice= (+ =percolation_lattice_variant=).
- Pore diameters: =get_pore_dia_lattice(..., variant="v2")= → =pore_dia_lattice=.

| Rank | Lattice variant | PLR / history | When to use |
|------+-----------------+---------------+-------------|
| 1 | *v2* | =find_pore_limiting_radius2=, axis keys =x,y,z= | Default lattice; better periodic BC |
| 2 (deprecated) | v1 | =find_pore_limiting_radius=, axis keys =0,1,2= | Old results only |

** window_fp (winding only)

Parameter =window_fp= on winding SA/vol functions (formerly =window_fp_for_accessible= on deprecated aliases).

| =window_fp= | Behaviour |
|-------------+-----------|
| =True= (default) | Winding percolation **plus** BFS rescue of fragments behind sub-probe graph windows matched by chemical shell fingerprint (see =docs/window_fingerprinting.org=). |
| =False= | Strict winding percolation only — same region logic as Chao's reference MC script (no fingerprint bridge). |
| *N/A on lattice* | Lattice functions do not accept =window_fp=. |

* Surface area estimators

** Mesh (=compute_surface_area_mesh_*=)

#+begin_src text
  dgrid  →  marching cubes at isovalue probe_radius
         →  trimesh.area (Å²)  →  m²/g
         →  split triangles by watershed fragment (regions)
         →  sum areas of percolating fragments only
#+end_src

- Deterministic; can fail or under-count when isosurface is fragmented or triangles span region boundaries (those triangles are discarded in per-fragment split).
- Inner helpers: =get_isosurface_mesh=, =get_isosurface_submeshes= (=mofography/visualize.py=).

** Monte Carlo (=compute_surface_area_mc_*=)

#+begin_src text
  random grid samples where |dgrid - probe| ≤ shell_thickness/2
  accessible SA ∝ (hits in shell ∩ percolating regions) / n_samples × V_cell / δ
#+end_src

- Stochastic (~few % noise); samples **fragment** =regions= labels (not =regions_pbc=).
- Generally **more accurate** than mesh for the same accessibility set.

** Void volume (=compute_void_volume_*=)

- Voxel count where =dgrid > probe= per fragment; not mesh-based.
- Pairs with same accessibility choice as SA (=_winding= / =_lattice=).

* Function reference

| Public function | Accessibility | Geometry | Notes |
|-----------------+---------------+----------+-------|
| =compute_surface_area_mesh_winding= | winding | mesh | Optional =window_fp= |
| =compute_surface_area_mesh_lattice= | lattice v1/v2 | mesh | =variant="v2"= default |
| =compute_surface_area_mc_winding= | winding | MC shell | Optional =window_fp=; **preferred SA** |
| =compute_surface_area_mc_lattice= | lattice v1/v2 | MC shell | Zeo++-style comparison |
| =compute_void_volume_from_results_winding= | winding | voxels | Optional =window_fp= |
| =compute_void_volume_from_results_lattice= | lattice | voxels | |
| =compute_percolation_history_winding= | — | stores =percolation_history_winding= | |
| =compute_percolation_history_from_results_lattice= | — | stores =percolation_history_lattice= | |
| =get_pore_dia_mgr_winding2= | winding | LCD/PLD/DFSD | → =pore_dia_winding= |
| =get_pore_dia_lattice= | lattice | LCD/PLD/DFSD | → =pore_dia_lattice= |

Deprecated aliases (still work): =compute_surface_area_from_results= → mesh winding; =compute_surface_area_from_results_mc= → MC winding; =*_from_results_*= variants.

Helpers: =mofography/percolation_results.py= (=get_percolation_history=, =store_pore_dia=, …).

* Results dict — dual storage

Both accessibility methods can coexist on one segmentation =results= object:

| Key | Written by |
|-----+------------|
| =percolation_history_winding= | =compute_percolation_history_winding=, winding SA/vol auto-fill |
| =percolation_history_lattice= | =compute_percolation_history_from_results_lattice= |
| =percolation_lattice_variant= | =v1= or =v2= when lattice history stored |
| =pore_dia_winding= | =get_pore_dia_mgr_winding2= (dict: lcd, pld, dfsd, plr, …) |
| =pore_dia_lattice= | =get_pore_dia_lattice= |

Legacy =percolation_history= is read-only fallback for old pickles; new code should use method-specific keys.

* Examples

** Segmentation (once per structure)

#+begin_src python
import mofography as mgr
from ase.io import read

mat = read("examples/TestCIFs/P1-IRMOF-1.cif")
dgrid = mgr.dgrid_from_atoms_rust(mat, spacing=0.5)
results = mgr.do_periodic_segmentation_rust(
    dgrid, mat, spacing=0.5, return_dgrid=True, compute_connections=True
)
probe = 1.2  # Å probe radius (e.g. N2)
#+end_src

** Winding MC surface area (recommended)

#+begin_src python
sa_mc = mgr.compute_surface_area_mc_winding(
    results, mat, probe_radius=probe, n_samples=20000, window_fp=True
)
print(sa_mc["accessible_surface_area"], "m²/g")
print(sa_mc["by_region"])  # fragment IDs → accessible m²/g
#+end_src

** Strict winding without window FP (Chao-equivalent regions)

#+begin_src python
sa_chao_style = mgr.compute_surface_area_mc_winding(
    results, mat, probe_radius=probe, window_fp=False
)
#+end_src

** Mesh surface area (faster, less robust)

#+begin_src python
sa_mesh = mgr.compute_surface_area_mesh_winding(results, mat, probe_radius=probe)
#+end_src

** Lattice Zeo++-style comparison

#+begin_src python
sa_lattice = mgr.compute_surface_area_mc_lattice(
    results, mat, probe_radius=probe, variant="v2"
)
vol_lattice = mgr.compute_void_volume_from_results_lattice(
    results, mat, probe_radius=probe, variant="v2"
)
#+end_src

** Store both percolation histories and pore diameters

#+begin_src python
mgr.compute_percolation_history_winding(results)
mgr.compute_percolation_history_from_results_lattice(results, variant="v2")
mgr.get_pore_dia_mgr_winding2(results=results, mat_atoms=mat, auto_rerun=False)
mgr.get_pore_dia_lattice(mat, dgrid=results["dgrid"], results=results, variant="v2")

assert "percolation_history_winding" in results
assert "percolation_history_lattice" in results
assert "pore_dia_winding" in results
assert "pore_dia_lattice" in results
#+end_src

* Decision flow

#+begin_src text
Need accessible SA or void at probe r?
  │
  ├─ Polymer / graph-sensitive MOF → accessibility = WINDING
  ├─ Zeo++ paper comparison       → accessibility = LATTICE (v2)
  │
  └─ Geometry:
        SA  → prefer compute_surface_area_mc_*
        SA quick viz → compute_surface_area_mesh_* (know triangle-loss risk)
        Vol → compute_void_volume_from_results_*
#+end_src
