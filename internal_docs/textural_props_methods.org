* Textural Properties Calculation

Mofography provides a comprehensive suite for calculating textural properties, distinguishing between global (material-level) and pocket-wise (region-specific) analyses. This dual approach offers a more nuanced understanding of nanoporous materials, leveraging a high-performance hybrid Python/Rust codebase that rigorously handles periodic boundary conditions (PBC) and arbitrary crystal symmetries.

** Global Textural Properties

At the material level, global textural properties are derived from the complete distance grid and segmented regions. These properties are computed in a high-throughput fashion, with intelligent allocation of resources automatically using =Dask= [cite:@dask] for parallel processing across materials and within individual material calculations.

- *Largest Cavity Diameter (LCD)*: This metric represents the maximum accessible void space within the entire structure, directly obtained as twice the global maximum value in the distance grid.
- *Pore Limiting Diameter (PLD)*: The global PLD quantifies the largest probe radius capable of percolating through the material across all three crystallographic directions. Its determination involves an efficient binary search algorithm applied to the distance grid, incorporating periodic boundaries and 26-connectivity to identify continuous pathways.
- *Void Volume and Surface Area*: These properties are computed through probe-dependent accessibility analysis. Isosurfaces, representing the accessible void space for a given probe radius, are generated using the *Marching Cubes algorithm* [cite::Lorensen1987] (implemented in =skimage.measure.marching_cubes= and further processed using the =trimesh= library within =mofography/visualize.py=). This approach critically distinguishes between geometrically accessible values (total surface area and volume from voxels exceeding a probe radius threshold) and percolation-accessible values (regions connected to cell boundaries through periodic connectivity).
- *Pore Size Distribution (PSD)*: Global PSDs are calculated following the *Gelb and Gubbins method* [cite:@gelbgubbins]. For each sample point in the distance grid, the largest non-overlapping sphere that includes that point is identified, with its radius corresponding to the distance grid value at that location. The Rust implementation (=mgr_rust/src/lib.rs=) significantly optimizes this process. By employing pre-sorted voxel lists based on their distance values in descending order, the sphere-finding problem is reduced from an O(N²) brute-force approach to an O(N) average case through early termination once the largest sphere is found. This optimization, coupled with parallel processing via =Rayon=, enables efficient and accurate global PSD calculations.

** Pocket-wise Textural Properties

Pore segmentation into distinct, often convex, regions (pockets) offers significant advantages for a more localized and interpretable textural analysis. This approach simplifies the interpretation of properties within these well-defined segments.

- *Pocket Maximum Size (Local LCD)*: For individual pockets, the LCD concept translates to the "pocket maximum size," representing the largest sphere that can be inscribed within that specific convex region. This is directly obtained from the maximum distance grid value within each segmented pocket.
- *Windows (Local PLD)*: The concept of PLD at the global level is refined into "windows" when considering inter-pocket connections. These windows represent the narrowest constrictions between adjacent pockets, crucial for understanding the flow of guest molecules. The identification of these windows is a key output of the region adjacency graph construction, where edges between nodes (pockets) are annotated with window properties.
- *Pocket-wise Pore Size Distribution (PSD)*: Calculating PSDs for individual pockets provides granular insights into the material's heterogeneity. Unlike global PSD calculations that sample uniformly across the entire volume, which can yield poor statistics for smaller pockets, pocket-wise PSDs are generated by sampling a fixed number of points per region. This approach, combined with the fact that the largest sphere centered at a sample point will inherently have the same region label as the sample point itself (due to segmentation around local maxima), is highly beneficial for parallelizing pocket-wise sampling, as pore size calculations for each pocket can proceed independently without inter-region dependencies. The resulting pocket-wise PSDs typically exhibit a single dominant peak, though sharp cubical features (corners) in some pockets may introduce a series of smaller peaks of decreasing intensity at smaller radii. This behavior is fundamental to *Gelb and Gubbins PSDs*, which essentially approximate arbitrary 3D volumes with spheres; pocket-wise application makes them more manageable due to the consistent convexity of the segmented pockets. Mofography outputs pocket-wise PSDs at a constant number of samples per pocket, which can then be normalized by the pocket volumes to obtain their individual contributions to the global PSD. The Rust implementation (=mgr_rust/src/lib.rs=) further enhances this by enabling parallel and optimized pore size calculations for each pocket, similar to the global PSD approach.

Both global and pocket-wise calculations are underpinned by Mofography's rigorous adherence to periodic boundary conditions and its ability to handle arbitrary non-orthogonal crystal systems, ensuring the mathematical soundness of the derived textural properties.
