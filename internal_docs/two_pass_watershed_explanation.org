# Why Two Watershed Passes Are Needed

* Setup

Periodic cell [0..9] with one physical maximum at position 4 (pore A).
Padding thickness = 5 voxels on each side, periodic (wrap-around).

Periodic images of A in the padded domain:
- Left padding:  positions -6, -1  (copies from cell positions 4, 9)
- Cell:          position 4
- Right padding: positions 14, 19  (copies from cell positions 4, 9)

* Pass 1: Distinct-Marker Segmentation

Each periodic image gets its own unique label:

#+begin_src python :results output
import numpy as np

# Padded domain: [-6..19], cell is [0..9]
pos = np.arange(-6, 20)

# Distinct markers: each periodic image has its own label
# One physical maximum at 4, periodic copies wrap around
distinct_pos = np.array([-6, 4, 14])   # left image, real, right image
distinct_lbl = ["A_0", "A_1", "A_2"]   # 3 separate labels

dist = np.abs(pos[:, None] - distinct_pos[None, :])
distinct = [distinct_lbl[i] for i in np.argmin(dist, axis=1)]

print("Position:", pos)
print("Distinct: ", distinct)
print()
print("Cell [0..9]:")
print("  Pos:", pos[6:16])
print("  Lbl:", distinct[6:16])
#+end_src

#+RESULTS:
# Distinct segmentation — each periodic image has its own label
# Cell [0..9]: A_0 A_0 A_0 A_0 A_0 A_1 A_1 A_1 A_1 A_1
# Boundary between A_0 and A_1 inside cell: at position 5

* Pass 2: Merged-Marker Segmentation

All periodic images of A share ONE label:

#+begin_src python :results output
# Merged markers: all A-images share label "A_all"
merged_pos = np.array([-6, 4, 14])
merged_groups = ["A_all", "A_all", "A_all"]

merged = []
for p in pos:
    d = np.abs(p - merged_pos)
    merged.append(merged_groups[np.argmin(d)])

print("Position:", pos)
print("Merged:   ", merged)
print()
print("Cell [0..9]:")
print("  Pos:", pos[6:16])
print("  Lbl:", merged[6:16])
#+end_src

#+RESULTS:
# Merged segmentation — all periodic images share one label
# Cell [0..9]: A_all A_all A_all A_all A_all A_all A_all A_all A_all A_all
# No boundary inside cell — one continuous region

* Pass 3: Relabeling

Take distinct result, replace each periodic-image label with its group:

#+begin_src python :results output
# Maxima groups: {A_0, A_1, A_2} are all periodic images of the same pore
groups = {"A_0": "A_all", "A_1": "A_all", "A_2": "A_all"}
relabel = [groups[l] for l in distinct]

print("Position:", pos)
print("Distinct: ", distinct)
print("Relabeled:", relabel)
print()
print("Cell [0..9]:")
print("  Pos:", pos[6:16])
print("  Lbl:", relabel[6:16])
#+end_src

#+RESULTS:
# Relabeled — distinct result painted with group labels
# Cell [0..9]: A_all A_all A_all A_all A_all A_all A_all A_all A_all A_all
# Looks identical to merged... but look at the FULL padded domain

* Comparison on Full Padded Domain

#+begin_src python :results output
# Compact view showing all three passes side by side
def show(labels, name):
    s = " ".join(f"{l:>5}" for l in labels)
    # Mark cell boundaries
    cell_start = 6   # index where pos=0
    cell_end = 16    # index where pos=10 (exclusive)
    left = " ".join(f"{l:>5}" for l in labels[:cell_start])
    cell = " ".join(f"{l:>5}" for l in labels[cell_start:cell_end])
    right = " ".join(f"{l:>5}" for l in labels[cell_end:])
    print(f"{name:10s} | {left} | {cell} | {right}")

print("          " + " ".join(f"{p:>5}" for p in pos[:6]) +

* The Difference

Look at the LEFT padding (positions -6..-1):

| Pass      | Left padding labels | What it means                          |
|-----------|---------------------|----------------------------------------|
| Distinct  | A_0 A_0 ... A_0     | Left image is A_0, separate from A_1   |
| Merged    | A_all A_all ...     | All A-images flood together            |
| Relabel   | A_all A_all ...     | Painted over, but boundary still hidden |

**The hidden boundary in relabeling:**

In the distinct result, A_0 (padding) and A_1 (cell) are DIFFERENT labels.
The watershed drew a boundary between them at position 5 (inside the cell).
When you relabel A_0→A_all and A_1→A_all, the boundary at position 5
still exists — it just has the same color on both sides.

In the merged result, there is NO boundary at position 5.  The A-image
at -6 and the A-image at 4 are the SAME source.  A voxel at position 2
flows to whichever is nearer (-6 or 4); there is no competition between
them because they share one label.

* What the Boundary Looks Like in 2D/3D

In 1D the artifact is a single point.  In 3D periodic segmentation:

- Distinct pass: each periodic image gets its own 3D region
- The watershed draws a **2D sheet** where competing regions meet
- This sheet cuts through what should be one continuous pore
- Relabeling paints both sides the same color but the sheet remains
- Surface area counts every voxel face on this sheet as "pore surface"

Merged pass: the sheet never forms because periodic images share one label.

* Summary

| Pass      | Boundary inside cell | How it was created                    |
|-----------|----------------------|---------------------------------------|
| Distinct  | At position 5        | Watershed competition between A_0, A_1 |
| Merged    | None                 | Single source, no competition         |
| Relabel   | At position 5        | Same as distinct, just painted over   |

Relabeling changes colors but does not move fences.
