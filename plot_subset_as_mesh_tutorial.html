Subset visualization

This is a short tutorial on advanced visualization using mofography, where we apply a different opacity to different parts of a metal-organic framework. Essentially, we select all the aromatic rings of the framework and plot a trace for them in normal opacity, and then show the rest ofhte framework in reduced opacity, using the plot_mesh function inside mofography. The plot_mesh function if you look inside visualize.py, gives you access through all the arguments to the plotly mesh3d API as **kwargs. Please refer to the docstring and plotly docs for more information
