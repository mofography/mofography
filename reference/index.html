Function reference

You probably won’t need most of these functions. The core workflow is covered in the Learn tutorials; this reference lists everything the library exposes. Some functions are experimental, legacy or deprecated and are marked as such. Use the tags below to filter, or the groups inside each module.

Show:

Compute

Core algorithms for grids, regions, RAGs, paths, percolation, and surface area.

Recommended

Go-to functions for this module.

add_best_optuna_trial_to_rag_serial go-to Like add_best_optuna_trial_to_rag but without dask.bag.
add_env_cluster_pocket_types_to_rag go-to Convenience wrapper: stamp env_cluster types from PocketTypingResult.
add_pocket_types_to_rag go-to Stamp pocket-type labels on RAG nodes (parallel to cluster_geom_pbc).
compute_surface_area_mc_winding go-to Monte Carlo shell surface area with winding accessibility (optional window FP).
compute_surface_area_mesh_winding go-to Mesh (marching-cubes) surface area with winding accessibility (optional window FP).
compute_void_volume_from_results_winding go-to Void volume (voxel) with winding accessibility (optional window FP).
connections_from_regions_and_dgrid go-to Build region connections and window sites from labelled regions and the distance grid.
detect_periodic_maxima_direct go-to Periodic maxima detection using the original distance grid directly.
get_connections_for_rag go-to Find connections between regions in a region adjacency graph (RAG) and identify window locations.
get_energy_interpolator_tricubic go-to Create a tricubic energy interpolator from pre-built 8-channel grid.
get_percolated_paths_on_rag go-to Find percolated paths and limiting windows between RAG pockets (requires regions on rag.graph).
pbc_groups_from_segmentation go-to PBC pocket groups (excluding background label 0) from segmentation outputs.
rag_from_connections go-to Build a NetworkX region adjacency graph from connection tuples and maxima.
regions_from_dgrid go-to Label pore regions and maxima from a distance grid using watershed segmentation.
select_percolation_threshold go-to Select the appropriate threshold for percolation analysis.

Alternate

Valid, but not the default choice.

add_best_optuna_trial_to_rag alternate Run Optuna guest placement per pocket (Dask-parallel) and store best trials on RAG nodes.
add_pocket_psd_to_rag_with_pbc alternate Attach probe-occupiable pocket PSD histograms (Rust pocket-wise sampler) to RAG nodes.
add_pocket_psds_to_rag_from_segmentation alternate Attach probe pocket PSDs to a RAG built from segmentation.
add_vdw_hist_to_rag alternate Attach vdW energy histograms (and bin centers) to RAG nodes for clustering or plotting.
check_percolation_periodic2 alternate Return True if void voxels percolate along any axis (percolation_all_axes_periodic).
compute_percolation_history alternate Compute the percolation history with region and maxima information.
compute_percolation_history2 alternate Compute percolation history using correct periodic percolation logic.
compute_percolation_history_from_results alternate Attach lattice percolation history (v1 by default; prefer v2 via variant=‘v2’).
compute_percolation_history_from_results2 alternate Attach lattice v2 percolation history from segmentation results (compute_percolation_history2).
compute_percolation_history_from_results_lattice alternate Attach lattice percolation history under percolation_history_lattice.
compute_point_probe_reference alternate Compute point probe (probe_radius = 0) surface area and void volume as reference.
compute_surface_area_mc_lattice alternate Monte Carlo shell surface area with lattice accessibility.
compute_surface_area_mesh alternate Compute surface area analysis from pre-computed results dictionary.
compute_surface_area_mesh_lattice alternate Mesh (marching-cubes) surface area with lattice (voxel) accessibility — Zeo++-style.
compute_void_volume_from_results alternate Compute void volume analysis from pre-computed results dictionary with accessibility concerns.
compute_void_volume_from_results_lattice alternate Void volume (voxel) with lattice accessibility.
detect_periodic_maxima_enhanced alternate Enhanced periodic maxima detection that handles:
dgrid_from_atoms_cpu_hybrid alternate Modified dgrid computation using a hybrid AABB query and explicit distance calculation.
dgrid_from_atoms_gpu alternate Compute the distance grid on the GPU (alternative to the Rust dgrid_from_atoms_rust).
get_energy_interpolator alternate Build a scipy RegularGridInterpolator for a 3D energy grid, filling NaNs from local neighborhoods.
get_pld_for_rag alternate Estimate PLD from a RAG via supercell tiling, re-segmentation, and percolated-path analysis.
get_pore_dia_lattice alternate Lattice pore diameters; stores pore_dia_lattice on results when provided.
get_pore_dia_mgr alternate Compute the pore diameters (LCD, PLD, DFSD) from a CIF file.
get_pore_dia_mgr2 alternate Compute pore diameters (LCD/PLD/DFSD) using the periodic-aware percolation solver.
get_psd_on_rag alternate Compute pocketwise pore size distributions on a RAG using path-based sphere inflation.
get_rag_from_regions_and_grid alternate Build a skimage mean-color RAG from regions with centroid and optional maxima node properties.
gpd_aabb_hybrid alternate Hybrid approach combining an AABB neighbor search with vectorized distance calculations.
gpe_aabb alternate Sum Lennard-Jones energies at grid points via Freud ball query on a prebuilt AABB neighbor search.
setup_poisson_spectral_gpu alternate Set up the system for solving the Poisson equation using a spectral method.
solve_poisson_spectral_gpu alternate Solve the Poisson equation using a spectral method for non-orthogonal, periodic systems.

Other

Low-level helpers and building blocks.
